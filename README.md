# GPT代充安全吗？2026 国内 ChatGPT Plus / Pro 安全核验清单

这不是 GPT 代充平台排行榜，也不提供“绝对安全”承诺。它是一套购买前核验工具：先检查账号控制权、敏感凭证、价格与支付透明度、订单查询、失败处理、退款和售后边界，再决定是否付款。

> 30 秒结论：优先使用你自己的 ChatGPT 账号；任何服务方若索要密码、短信或邮箱验证码、恢复码、Passkey、Session/Cookie、API Key，或要求你长期使用共享账号，应立即停止。

## 在线核验工具

[打开 GPT 代充安全核验工具](https://fangmumu111-bot.github.io/gpt-daichong-safety-checklist/)

工具在浏览器本地计算，不上传答案，也不要求填写订单号、联系方式、IP、钱包地址或交易哈希。它只能识别明显风险，不能替代你对商家、支付渠道和售后条款的独立判断。

## 先看这 6 条红线

| 检查项 | 可继续核验 | 立即停止 |
| --- | --- | --- |
| 账号归属 | 升级你自己的账号 | 出售或长期出租共享账号 |
| 登录凭证 | 不索取密码 | 索要密码或让你关闭安全保护 |
| 身份验证 | 不索取验证码、恢复码、Passkey | 要求转发验证码或恢复凭证 |
| 会话与密钥 | 不索取 Session、Cookie、API Key | 要求复制浏览器会话或密钥 |
| 付款信息 | 价格、币种、网络和收款对象清楚 | 临时改价、地址或链网络不明 |
| 售后证据 | 有订单查询和公开规则 | 付款后无订单记录、无失败边界 |

出现任意一条“立即停止”，都不应被低价、限时或所谓“内部渠道”抵消。

## 5 分钟核验流程

1. 打开[完整核验清单](CHECKLIST.md)，逐项记录“通过 / 待确认 / 停止”。
2. 用[公开事实模板](EVIDENCE-TEMPLATE.md)记录页面链接和核验日期，不记录客户隐私。
3. 对照[风险模型](RISK-MODEL.md)，确认你理解共享账号、敏感凭证、支付错链和冒充官方等风险。
4. 付款前保存价格、支付方式、失败处理和退款边界的公开页面。
5. 如果已经出现异常，按[事件处理清单](INCIDENT-RESPONSE.md)止损。

## 最低通过条件

一项服务至少应同时满足：

- 使用购买者自己的账号，不把共享账号包装成会员升级；
- 明确声明不会索取密码、验证码、恢复码、Passkey、Session/Cookie 或 API Key；
- 在付款前公开价格、计价时间、实际支付方式和币种或链网络；
- 提供可验证的订单状态查询；
- 公开支付失败、超时、错链、退款与人工复核的边界；
- 不冒充 OpenAI 官方，不伪造评价、销量、成功率或第三方测评；
- 页面保留更新时间，过期信息能被纠正。

即使全部满足，也只能说明“已通过这份公开信息核验”，不能证明零风险。

## 这套项目能做什么

- `CHECKLIST.md`：适合人工逐项检查的 20 项清单；
- `checklist.json`：可供程序读取的同版核验项；
- `checklist.schema.json`：JSON Schema，便于校验第三方实现；
- `EVIDENCE-TEMPLATE.md`：不打分、不排行的公开事实模板；
- `RISK-MODEL.md`：风险、触发信号、可能影响和最低处置；
- `INCIDENT-RESPONSE.md`：付款或账号出现异常后的止损步骤；
- `SOURCES.md`：OpenAI 官方账号安全来源及核对日期。
