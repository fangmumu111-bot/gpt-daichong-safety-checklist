常见问题

GPT代充一定不安全吗？

不能只凭“代充”两个字下结论。重点是账号控制权、敏感凭证边界、付款透明度，以及订单、失败、退款和售后规则能否被公开验证。

为什么不能提供密码或验证码？

密码、验证码、恢复码、Passkey、Session、Cookie 和 API Key 都可能授予账号或资源访问能力。会员升级不应以交出这些凭证为前提。

清单全部通过就代表绝对安全吗？

不代表。全部通过只表示没有触发本清单覆盖的明显风险；第三方服务、平台规则和支付环境仍可能变化。
